# M0.1 — Device Contract Probe

The device implements the Exec lifecycle vectors Init, Open, Close, Expunge,
BeginIO, and AbortIO through a VBCC/vasm resident module. Unit 0 is supported;
other units and undersized requests fail with `IOERR_OPENFAIL`.

Implemented generic NDK commands are `CMD_READ`, `CMD_WRITE`, `CMD_CLEAR`,
`CMD_FLUSH`, and `CMD_RESET`. Unknown commands return `IOERR_NOCMD`. No numeric
serial command IDs are copied or guessed.

The modem state machine is `IDLE -> RINGING -> ONLINE -> IDLE`. It recognizes
line-oriented `AT`, `ATZ`, `ATA`, and `ATH`, with the responses required by the
probe. A 512-byte receive FIFO queues replies, and reads remain pending until
their requested byte count is available. Abort and last-close complete pending
reads with `IOERR_ABORTED`.

`ABBTCP_CMD_INJECT_RING` is a test-only third-party command at the project
private base `CMD_NONSTD + 0x0100`. It is intentionally above the serial
commands defined by NDK `devices/serial.h`; it is not an ABBS or production
modem command.

## Probe sequence

1. Create a message port and an `IOExtSer` request.
2. Open `abbstcp.device`, unit 0.
3. Write `AT\r`, read `OK\r\n`.
4. Inject the synthetic call, read `RING\r\n`.
5. Write `ATA\r`, read `CONNECT 38400\r\n`.
6. Write `ATH\r`, read `NO CARRIER\r\n`.
7. Close the device and exit with return code 0.

## Diagnostics

Each BeginIO log contains unit, NDK command number, flags, requested and actual
length, escaped write payload, completion/queue event, and modem state
transition. Output uses the NDK `debug.lib` kernel debug channel and never
modifies caller data. Later ABBS testing should capture this output through the
emulator's serial/debug facility.

Host `make check` verifies source invariants only. Follow the exact FS-UAE
commands in the project README for authoritative acceptance.
