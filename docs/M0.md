# M0 — Device Contract Probe

## Acceptance criteria

- `abbstcp.device` builds for classic AmigaOS 3.x / 68k
- installs in `DEVS:`
- `OpenDevice("abbstcp.device", 0, ...)` succeeds
- probe can issue write/read exchanges for AT/ATZ/ATA/ATH
- synthetic `RING` can be injected
- unsupported commands fail cleanly
- no socket code exists yet
- no ABBS data is modified

## Suggested validation order

1. Build device and probe.
2. Copy device to `DEVS:`.
3. Run probe.
4. Only after probe stability, configure a disposable ABBS node:
   - Device: `abbstcp.device`
   - Unit: `0`
5. Capture/log every device command ABBS sends.
6. Use those observations as the M1 contract.
